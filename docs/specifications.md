# Reversa 技術仕様書 (Technical Specifications)

本書では、Reversa（逆暗証トレーニング）のコアとなるシステムロジックや、データ構造に関する詳細な仕様を記述します。
（対象バージョン: v0.2.0〜）

---

## 1. 音声認識エンジン (Voice Recognition)

ユーザーの音声入力をテキストに変換するために、OpenAIの **Whisper API (`whisper-1` モデル)** を採用しています。

- **採用理由:** 音声データのノイズ耐性が高く、特に短い単語や「逆から読む」といった不自然な発音に対しても高い認識精度を誇るため。
- **録音と送信フロー:** 
  ブラウザの `MediaRecorder` で `audio/webm` 形式として録音し、VAD（Voice Activity Detection：発話区間検出）によって発話の終了を自動検知した時点で、BlobデータとしてWhisper APIに送信します。

## 2. 音声合成エンジン (Text to Speech)

問題の読み上げ（音声合成）には、OpenAIの **TTS API (`tts-1` モデル)** を採用しています。

- **採用理由:** 肉声に近い自然なイントネーションを実現するため。
- **設定:** 男性ボイスである `onyx` を使用し、ゲームのテンポを崩さないように読み上げ速度（`speed`）を `0.85` 〜 `0.95` に細かく調整して生成しています。

---

## 3. 難易度別：自動録音停止（無音判定）の閾値

ユーザーが発声したあと、「話し終わった」とシステムが判定して録音を終了するまでの**無音待機時間（サイレンススレッショルド）**は、難易度に応じて動的に変化します。

| 難易度（レベル） | 文字数の目安 | 無音判定の待機時間 | 理由 |
| :--- | :--- | :--- | :--- |
| **初級編 (Beginner)** | 3文字 | **1.5秒 (1500ms)** | 文字数が少ないため、すぐに答え終わると想定しテンポを重視 |
| **中級編 (Intermediate)** | 4〜6文字 | **2.5秒 (2500ms)** | 途中で少しつっかえたり、考えながら話す時間を許容 |
| **上級編 (Advanced)** | 7〜10文字 | **3.5秒 (3500ms)** | 長い単語を逆から読むため、途中で数秒間言葉に詰まるケースを想定 |

*※補足: いずれの難易度でも、最大録音時間は「20秒（`MAX_RECORDING_TIME`）」で強制打ち切りとなります。*
*※無音状態が5秒間（5000ms）続いた場合は、スキップとみなして処理を終了します。*

## 4. 問題のデータ構造 (Data Structure)

設問データは `questions.js` にて一元管理されており、以下のようなJSONオブジェクトの配列として定義されています。

```javascript
{
    "word": "きつね",                    // 漢字・ひらがなを含む文章（OpenAI TTSでの自然な読み上げ用）
    "ruby": ["き", "つ", "ね"],          // 一文字ずつリズムで読むための配列
    "reverse": "ねつき",                 // 逆順の読み（正解判定用。ひらがな）
    "bg": "bg_beginner_1.png"          // プレイ中の背景画像ファイル名
}
```
- **ポイント:** 自然な発音（連続音）モードの時は `word` を読み上げ、一文字ずつリズムで読むモードの時は `ruby` の配列を利用するように設計されています。（※現在、拗音（ゃゅょ）や長音（ー）は判定の複雑化を防ぐため問題データから除外する方針としています）

---

## 5. 誤判定を吸収する「ファジーマッチング」と「切り捨てロジック」

Whisperは優秀な音声認識エンジンですが、ユーザーが「答えは、〇〇です」と喋ってしまったり、AI特有の幻覚（ハルシネーション）による謎の文字が混入したりすることがあります。
これらを吸収し、純粋に「逆から読めているか」だけを判定するために、以下の文字列クリーニング（正規化）処理を行っています。

### ① 前後の不要な言葉の切り捨て（Trim）
- **文頭の除外:** `「答えは」「回答は」「単語は」「いうのは」「それは」「正解は」` などの言葉が入っていた場合は削除します。
- **文末の除外:** `「です」「でした」「になります」` といった語尾を削除します。

### ② 記号や表記ゆれの吸収
- `「」『』（）()[]"'` や、読点 `、。！?？`、空白、ハイフン、長音記号（ー）などはすべて無視（削除）します。
- 漢字の数字（一、二、三...）や全角数字（０-９）は、すべて半角の算用数字（0-9）に変換します。
- 最終的に**「ひらがな」と「半角数字」以外の文字はすべて削除**し、純粋な音の並びだけに絞り込みます。

### ③ 幻覚（ハルシネーション）の自動リトライ処理
無音の録音データが送られた際などに、Whisper APIが勝手に「ご視聴ありがとうございました」「チャンネル登録お願いします」と出力してしまう現象（ハルシネーション）の対策を入れています。
- `「視聴」「チャンネル」「登録」` が含まれる場合。
- 答えの文字数（モーラ数）が20文字を超える異常な長さの場合。
- 正解の文字数と、認識した文字数に「2文字以上の差」がある場合。
👉 **上記に該当する場合は「不正解」とせず、「うまく聞き取れませんでした」としてユーザーに再入力（リトライ）を促します。**

### ④ 最終判定
クリーニングされた文字列（`cleanedAnswer`）と、正解の文字列（`normalizedCorrect`）が完全に一致した場合のみ、「正解（お見事）」と判定します。
